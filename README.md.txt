# Brain Tumor Detection using Deep Learning

## Project Overview

This project uses MobileNetV2 and TensorFlow to detect brain tumors from MRI images.

## Dataset

* Brain Tumor MRI Dataset
* Classes:

  * Yes (Tumor)
  * No (No Tumor)

## Technologies Used

* Python
* TensorFlow
* Keras
* MobileNetV2
* Matplotlib

## Model Performance

* Validation Accuracy: 98%

* brain_tumor_detection.py
